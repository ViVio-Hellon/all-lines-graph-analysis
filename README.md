# 全ライン グラフ分析(all-lines-graph-analysis)

日報管理ツール([ViVio-Hellon/all-tools](https://github.com/ViVio-Hellon/all-tools))が書き出した
各ラインの集計データを横断して、ライン別の実績を比較・分析する独立アプリです。
既存の日報入力・集計・共有DBには手を加えず、**読むだけ**です。

画面は **ダッシュボード**(グラフの自由配置)と **設定**(参照設定・配布設定・ログ・管理者)の2つです。
調べたことと確認をお願いしたいことは [docs/調査結果と未確定事項.md](docs/調査結果と未確定事項.md) にあります。

## 動かし方

**追加ライブラリは要りません**(各ラインPCの Python に入れられないため、標準ライブラリだけ)。

| | |
|---|---|
| `全ライン グラフ分析.exe` | **デスクトップ版(ふだんはこれ)**。専用の窓で動き、**ポートを使わない**。作りは [docs/デスクトップ版.md](docs/デスクトップ版.md) |
| `Start.vbs` | 予備のブラウザ版(コンソールを出さない。127.0.0.1 で待ち受け、ブラウザで開く) |
| `start.bat` | 予備のブラウザ版の診断起動(経過を表示)。`start.bat --check` で設定と大本のたどり方を表示して終わる |

**ブラウザ版とデスクトップ版は同時に動きません。** どちらを後から開いても、理由を出して止まります。

```
全ライン グラフ分析.exe(Rust/Tauri) … 窓・Python の起動と見張り・多重起動と排他・閉じるときの確認
  └ 標準入出力 → bridge.py(Python) … ポート無しの入口
Start.vbs / start.bat → start_app.py … ブラウザ版(127.0.0.1)
  どちらも → graphapp.server.Exchange(同じ振り分け)→ graphapp/(標準ライブラリだけ)
グラフは自前の SVG で描く(CDN を使わないので、ネットに出られないPCでも動く)
```

## ダッシュボード

| できること | 中身 |
|---|---|
| **指定ライン × 指定グラフ**(メイン) | 「グラフ追加」でラインと項目をいくつでも選ぶと、ライン × 項目 の数だけカードができ、同じページに並ぶ(L-1 生産重量 / L-2 稼働率 / L-3 停止理由別 時間 …)。カードは「ライン指定」になり、共通条件や切り替えでは変わらない |
| ライン切り替え | 共通条件の「表示」を「1ラインずつ切り替える」にすると、ラインのタブ(← → キーでも)が出て、**ページのすべてのグラフがそのラインだけ**になる。「すべて並べる表示に戻す」で、それぞれのカードのラインに戻る |
| 共通条件 | 対象ライン(全ライン・個別・複数・全解除)、集計期間(今月・先月・直近7/30/90日・今年・去年・指定)、集計単位(日・週・月・年)、直 |
| グラフ追加 | ① ライン(指定する / 共通条件に従う・ラインごとに別カード) ② 項目(検索欄・分類タグ・項目カード、複数可) ③ 種類(項目ごとのおすすめ、または指定)。取れない項目は理由つきで選べない |
| ライン比較 | 複数ラインを1つのグラフに重ねず、**ラインごとに独立したグラフ**を並べる。ラインの色はどのグラフでも同じ |
| グラフの種類 | 棒・横棒・折れ線・積み上げ棒(直や分類の内訳)・円(構成比)。合わない種類は選べず、理由を出す。種類を変えても条件はそのまま |
| 組み合わせ(棒+線) | 棒(左の軸。直ごとの積み上げか合計)に、右の軸の線を重ねる: **日毎累計と目標の45度線**(生産枚数。ライン毎目標のCSV)、または別の項目(稼働率など) |
| ライン速報 | グラフの上の帯に、ラインごとの今の直・その直の枚数・今日の合計・直ごとの枚数・目標との差(%)・保存した時刻を出す。日報管理ツールが日報を保存するたびに書く `<ライン>.json` を30秒ごとに読む(計算し直さない)。今日の速報でなければ日付を出し、しばらく保存が無ければ印を付ける。出すラインは「共通条件に従う」(既定。切り替え表示にも従う)か「ラインを選ぶ」(選んだラインだけ)。選び方はダッシュボードに保存され、配布設定のダッシュボードと一緒に配られる |
| 自動更新 | 1分ごとに集計CSVを確かめ、数が変わったカードだけ描き直す(画面が裏にある・設定を開いている間は休む)。「データを読み直す」でもすぐ読める |
| グラフの設定 | タイトル・項目・種類・対象ライン/期間/単位/直(共通か、このグラフだけか)・色・凡例・数値ラベル・縦軸の目盛りをそろえる・縦軸の範囲 |
| 自由配置 | 見出しをつかんで移動、右下の角で大きさを変える(12列の格子。重なったら下へ押し出す)。キーボードは矢印で移動、Shift+矢印で大きさ |
| 保存 | 新規・上書き・別名・複製・削除・呼び出し。前回開いたものを起動時に開く。別の窓が先に保存していたら上書きしない |
| 出力 | 印刷・PDF(印刷画面で「PDFに保存」)、CSV・画像(設定の「CSV・画像の書き出し先」へ書く。ブラウザのダウンロードは使わない) |

項目ごとの出どころ(CSVのどの列か)と、まとめ方は `graphapp/metrics.py` の冒頭にあります。
見本データで試すときは次のとおりです(作り物の数です)。

```bash
python -m tests.sample_data 見本\集計出力 120
```

## 設定タブ

### 参照設定 ── 集計データは「大本」だけ決める

all-tools の集計CSVは次の形で書き出されます(`tools/nippou/nippou/reporting/csv_export.py`)。

```
<大本>\<ライン>\集計\<yyyy.mm>\<dd>\集計_<yyyy-mm-dd>_<ライン>.csv
                                    集計明細_<yyyy-mm-dd>_<ライン>.csv
                                    停止内訳_<yyyy-mm-dd>_<ライン>.csv
```

**設定するのは `<大本>` だけ**です。ライン・年月・日のフォルダはアプリがたどります
(`graphapp/agg_store.py`)。

* 大本の下の `<フォルダ>\集計\` を持つものがライン(L-2 が L-10 より先に並ぶ)
* 期間の外の年月フォルダは開かない(共有では開くだけで遅い)
* ラインのフォルダや `集計` フォルダを指してしまっても読める(どの段を指しているか画面に出る)
* all-tools が日付を読めなかったときに `集計\` 直下へ出したCSVも、ファイル名の日付で拾う
* 2つ目の大本(all-tools の「集計CSVの出力パス(2つ目)」)は、1つ目に無い日・種類だけ拾う
* 大本を決めていない端末は、同じPCの日報管理ツールの既定の出力先(`%LOCALAPPDATA%\NippouTool\work`)を見る

| 欄 | 鍵(`user_config.json`) | 管理者の鍵 |
|---|---|---|
| 集計データの大本 | `report_output_dir` | 要 |
| 集計データの大本(2つ目) | `report_output_dir_2` | 要 |
| 共有の日報データの置き場所 / ファイル名 | `access_dir` / `access_db_filename` | 要 |
| ログの出力パス | `log_dir` | 不要 |
| CSV・画像の書き出し先 | `graph_export_dir` | 不要 |
| ライン毎目標のCSV(45度線) | `line_target_file`(all-tools と同じ鍵) | 不要。ファイルでもフォルダ(その下の `ライン毎目標.csv`)でもよい。書き方は `L-1,120`(1日あたりの枚数) |
| ライン速報の置き場所 | `flash_report_dir`(all-tools と同じ鍵) | 不要。日報管理ツールの「ライン速報の置き場所」と同じフォルダ。`<ライン>.json` を読む |

鍵の名前は all-tools と同じにしてあります。画面の作りも all-tools の参照設定と同じです
(欄ごとに保存・「未保存 / 保存しました」の表示・実際に見る道・「フォルダを選ぶ…」・いまの状態を読み直す)。
「集計データを確かめる」で、ラインと期間を選ぶと大本からたどった各日のCSVが一覧で出ます。

### 配布設定

all-tools の `distribution.py` と同じ決まりです。

1. 1台で参照設定を決め、「配布設定を書き出す」(管理者パスワード)
2. `Start.vbs` と同じフォルダに `配布設定\`(`設定.json` / `はじめに読む.txt`)ができる
3. フォルダごと配る → 配った先は起動時に読み込む
4. **その端末で決めた値は上書きしない**(無い項目だけ埋める)。配布設定から読み込んだ値のままの
   項目は、配り直した新しい値で置き換える。揃えたいときは「配布設定を読み込み直す」
5. この端末の設定ファイルを読めないときは、書き出しも読み込みもしない
6. 別のアプリ(all-tools)の配布設定は読まない
7. **組んだダッシュボードも入れられる**(既定で入る)。`配布設定\ダッシュボード.json` に名前と構成を書く。
   配った先は、同じ名前が無ければ取り込み、配布設定から取り込んだまま直していなければ配り直した中身に置き換える。
   その端末で作った・直したダッシュボードは上書きしない(「読み込み直す」のときだけ上書き)。その端末にだけあるものは消さない

### ログ

```
<ログの出力パス>\all_lines_graph\
  all_lines_graph_動作記録_<端末>.log               動いた記録(5MBで回す)
  all_lines_graph_出来事_<yyyy-mm-dd>_<端末>.jsonl   エラー・注意・操作(半年残す)
  all_lines_graph_起動_<端末>.log                   起動の記録
```

* ツール名のフォルダ + ファイル名にツール名と端末名(all-tools の `log_names.py` と同じ形)
* 設定の先に書けなければこの端末(`%LOCALAPPDATA%\AllLinesGraph\logs`)へ書き、理由を画面に出す
* パスを変えたら再起動せずに書き先を移す
* 取得時間・対象期間・ラインは `logging_setup.timed()` で1行に残す(要件定義 8 のログ)

## この端末だけのもの

```
%LOCALAPPDATA%\AllLinesGraph\
  runtime\user_config.json   この端末の設定
  logs\all_lines_graph\      ログ(既定)
  data\dashboards.sqlite3    組んだダッシュボード(アプリ専用DB。端末ごと。ほかの PC へは配布設定で配る)
  work\<yyyy.mm>\            CSV・画像(書き出し先を決めていないとき)
```
